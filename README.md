# godotris

## Prerequisites
- Godot 4.7

## Run

Open `project.godot` in Godot and press `F5`.

Or from a terminal:

```sh
mise run build
```

or

```sh
godot --path .
```

## Controls

| Action | Keys |
|---|---|
| Move | `A` `D` / `←` `→` |
| Soft drop | `S` / `↓` |
| Rotate | `W` `Space` / `↑` |
| Pause | `P` |
| Restart | `R` |
| Quit | `Q` |
